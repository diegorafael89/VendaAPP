Backup & Recuperação do Banco de Dados

O sistema armazena todos os registros no banco de dados SQLite persistente. Você pode exportar ou restaurar uma cópia completa em JSON com validação atômica.

Informações Técnicas
  • Banco de dados: SQLite (com WAL mode e chaves estrangeiras)
  • Autenticação: Criptografia PBKDF2 com Salt e Sessões Seguras
  • Formato de Interface: HTML5 nativo com Bootstrap 5.3 e Chart.js
  • Versão do Sistema: 2.0.0 (Revisão Segura)
